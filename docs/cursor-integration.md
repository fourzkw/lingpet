# Cursor 接入

先按 [快速开始](getting-started.md) 安装 Windows 桌面版，再从工作台添加 Cursor 接入。当前桌面版通过本机 Hooks 和 MCP 接入，无需另装旧版 VSIX 侧边栏，也无需为灵伴安装系统 Node.js。

## 安装与验证

1. 确认本机已安装 Cursor。
2. 在灵伴工作台「Agent 接入」选择 Cursor。默认使用用户目录下的 `.cursor`；多套环境可在高级选项中选择相应配置目录，无需填写 Cursor 命令或 profile。
3. 点击「安装接入插件」，阅读完成提示。
4. 重新加载 Cursor 窗口，或完全退出后重新打开。
5. 新建 Agent 会话并发送一条消息，在灵伴接入页确认收到真实会话事件。
6. 选择桌宠，在「跟随」页选择「仅跟随 Cursor」或「自动跟随所有来源」；若在动作试映，点击「恢复实时动作」。

接入会合并灵伴拥有的 Hooks 和独立命名的 MCP 入口，保留其他配置。配置已安装不代表已收到事件，需完成真实会话验证。

## 更新和故障排查

本体按接入内容变化更新已启用的托管接入；更新后请按提示重载 Cursor。接入页提供「检查」「更新接入」和「重新安装接入」，操作记录和配置备份保存在数据目录的 `integrations/transactions`。

未收到事件时，检查接入配置目录是否对应当前 Cursor 环境，完成重载后新建会话重试。如果之前使用旧版 VSIX，请先在扩展管理中停用或卸载，再重开 Cursor，避免旧运行时同时启动。

工作台可从桌宠右键菜单、系统托盘、桌面或开始菜单打开。从托盘退出灵伴后，Hook 不会重新启动本体；需要手动打开灵伴。

## 适用范围

当前面向同一台 Windows 电脑、同一用户下运行的 Cursor。WSL、容器和远程主机中的 Agent 不会自动连接本机桌宠。状态变化取决于宿主实际派发的事件，不依据回答文字推断。

接入管理和数据目录见 [安装与接入管理](desktop-installation.md#agent-接入与更新)；诊断与反馈见 [快速开始](getting-started.md#5-日常使用与排查)。
