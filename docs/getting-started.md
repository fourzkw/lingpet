# 快速开始

灵伴当前支持 Windows x64 本机环境。安装后即可显示桌宠、点击和摸头；想让桌宠跟随 AI 工作状态时，再按需接入 Codex、Cursor 或 DSH。

## 1. 下载并安装

1. 打开 [GitHub Releases](https://github.com/fourzkw/lingpet/releases/latest)，下载 `LingPet-Setup-<版本号>.exe`。
2. 运行安装程序，选择独立的程序文件夹，按提示完成安装。
3. 从桌面或开始菜单打开「灵伴」。

安装程序已包含 Electron、私有 Node.js 和灵伴所需运行环境，无需为灵伴另装 Node.js、npm 或 pnpm，首次启动也无需下载 Electron。Agent 宿主需自行安装，并满足其自身的运行要求。

安装和数据位置、升级方式见 [安装与数据目录](desktop-installation.md)。

## 2. 显示第一只桌宠

1. 在工作台左侧「我的桌宠」选择伙伴；列表为空时，点击「新增桌宠」。
2. 点击「显示到桌面」，拖动桌宠调整位置。
3. 点击或摸头可触发形象提供的互动；右键桌宠可打开快捷控制。

首次安装和新建桌宠默认「不跟随会话」，可以先保持待机陪伴。安装包内置 Claude 像素形象；其他形象可在「桌宠市场」安装，也可导入本地 `.petpack`。

显示桌宠、互动和本地动作播放不需要模型 API Key。AI 创作所需的生成服务可在之后配置，见 [生成服务配置](generation-services.md)。

## 3. 按需接入 Agent

只需接入自己使用的宿主。宿主和灵伴需在同一台 Windows 电脑、同一用户下运行；当前不支持从 WSL、容器或远程主机连接 Windows 桌宠。

1. 打开工作台「Agent 接入」，选择 Codex、Cursor 或 DSH。
2. 确认检测到正在使用的宿主；多套环境可在高级选项中选择配置位置。
3. 点击「安装接入插件」，按完成提示操作。

| 宿主 | 安装后需要做什么 |
| --- | --- |
| Codex | 完全退出并重新打开，确认插件启用，按宿主提示审核并允许灵伴 Hooks，再新建会话。 |
| Cursor | 重新加载窗口或退出后重新打开，再新建 Agent 会话。 |
| DSH | 确认配置目录和 profile 对应当前实例，重启 DSH，再发送消息。 |

详细说明：[Codex 接入](codex-integration.md) · [Cursor 接入](cursor-integration.md) · [接入管理与更新](desktop-installation.md#agent-接入与更新)。

## 4. 验证真实连接

1. 在已接入的宿主中新建会话并发送一条消息。
2. 查看「Agent 接入」中的连接状态，确认已收到真实会话事件。
3. 选择桌宠，在「跟随」页将「会话范围」设置为对应来源或「自动跟随所有来源」。
4. 如果正在「动作试映」，点击「恢复实时动作」，再观察桌宠是否随工作状态变化。

安装接入成功、管理通道连接或动作试映，都不能单独证明会话事件已接通。手动选择「不跟随会话」后，后续重连不会自动恢复跟随；可随时在「跟随」页重新选择。

## 5. 日常使用与排查

- **打开工作台**：使用桌面或开始菜单快捷方式，也可从桌宠右键菜单或系统托盘打开。
- **完全退出**：从系统托盘退出灵伴；关闭工作台窗口会继续保留桌宠。
- **没有收到事件**：检查宿主插件是否启用、是否完成重启和 Hooks 审核、配置目录是否选对，然后新建会话重试。
- **收到事件但桌宠没变化**：检查桌宠是否已显示、跟随来源是否匹配，以及是否仍在动作试映。
- **市场下载失败**：查看界面显示的线路和错误，修复网络后重试；无需删除已有形象或设置。
- **需要报告问题**：在「应用设置 → 版本与诊断」导出诊断，附上应用和宿主版本、复现步骤。分享前检查本机路径及错误信息，移除敏感内容。反馈入口为 [GitHub Issues](https://github.com/fourzkw/lingpet/issues)。

升级、卸载和重装见 [卸载与重装](uninstall-and-reinstall.md)。开发者从源码运行及构建的要求见 [README](../README.md#从源码运行)。
