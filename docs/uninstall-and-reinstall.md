# 卸载与重装

0.6.15 起提供卸载预览、保留数据卸载，以及备份数据后重置。仅操作灵伴拥有的 Hooks 和本地副本，第三方 Hooks、策略和信任哈希保持原样。

## 先预览

在包含 `bin` 的插件运行时目录执行：

```powershell
node bin/board-pet.js uninstall
```

该命令只显示要处理的配置、数据目录和宿主卸载步骤。没有 `--apply` 不会停止服务或修改文件。

## 保留数据重装

1. 在 DSH、Codex、Cursor 的插件／扩展管理中卸载灵伴，完全退出这些宿主，避免它们在清理过程中重新注册 Hooks。先将独立安装包解压到插件目录以外，便于关闭宿主后运行清理命令。
2. 在解压后的运行时目录执行：

```powershell
node bin/board-pet.js uninstall --apply
```

清理会暂停自动唤起，移除灵伴的 Codex／Cursor 用户级 Hooks，移除灵伴迁移留下的插件 Hook 禁用覆盖，保留信任哈希和其他插件配置，清除属于当前数据目录的 Windows 开机启动项，停止已认证的后台服务，并将 Cursor 本地副本和生成的 Codex 启动器移到备份目录。此流程不替代宿主自己的插件管理器，不修改宿主的插件安装数据库。

桌宠配置、已安装形象、创作项目、运行时和下载缓存继续保留。重新安装宿主包后，显式点击“启动桌宠”或“打开工作台”，解除暂停标记；重新检查 Hooks 的启用和审核状态。卸载不会替你批准新的 Hooks。

## 模拟新用户的干净重装

先关闭并卸载所有宿主插件，再执行：

```powershell
node bin/board-pet.js uninstall --apply --archive-data
```

整个用户目录会移动到同级 `BoardAiPet-uninstall-backups/<时间与随机编号>/user-data`，不会永久删除形象、项目或密钥配置；原位置仅留下阻止自动唤起的暂停标记。命令输出具体备份位置并保存 `result.json`。重装后显式启动时，将生成默认配置，默认只有 Claude 像素形象，并需重新准备 Electron。联网下载失败时先解决网络或运行时获取问题，不能据此判断宿主安装失败。

若后台仍未退出或目录被占用，操作会报错并保留数据，不强杀无关进程，也不继续移动用户目录。按提示关闭宿主后重试。所有备份都在自动发现的插件目录之外。

需要恢复时，先退出桌宠和宿主，将新生成的用户目录另行备份，再把备份中的 `user-data` 放回原位置；只恢复与灵伴相关的 Hooks，不要用旧宿主配置整体覆盖现在的其他插件设置。

## 接入修复

新版本启动成功后会将已校验的运行版本同步到共享启动记录，清除该版本的误报失败标记；延迟的启动器不能回退健康版本。Cursor 扩展会校验本地插件副本并备份更新，已安装的较新版本不会被旧扩展降级。VSIX 的版本号与桌宠版本一致。
