# 卸载与重装

本文适用于通过 `LingPet-Setup-<版本号>.exe` 安装的 Windows 桌面版。卸载默认保留设置、已安装形象、创作项目与内容数据。

## 只移除某个 Agent 接入

在工作台「Agent 接入」找到对应接入，点击「卸载接入」。这会撤销并清理灵伴拥有的注册，不卸载 Agent 宿主，也不影响其他接入和桌宠数据。

如提示宿主待清理或文件被占用，按页面说明关闭相关宿主后重试。卸载或停用的接入不会在下次启动时自动安装。

## 卸载桌面版

1. 在「应用设置 → 常规 → 数据与内容目录」记下数据位置，重要内容可先备份。
2. 保存 Agent 中的工作并关闭相关宿主，从系统托盘退出灵伴。
3. 在 Windows 应用列表中找到「灵伴」，运行卸载程序并按提示完成。

卸载会先撤销和清理托管的 Agent 接入，再退出本体并删除程序文件；内置或外部数据目录继续保留，含数据的安装父目录也可能保留。

清理结果写入数据目录中的 `uninstall.log`，维护失败详情写入 `maintenance-error.log`。遇到失败先查看提示和日志，关闭占用文件的宿主后重试。

## 保留数据重装或修复

仅升级时，直接运行更高版本安装程序即可，通常无需卸载。详见 [升级桌面版](desktop-installation.md#升级桌面版)。

需要重装时，可先按上述步骤卸载，再运行安装程序。尽量沿用原程序位置；安装后核对「数据与内容目录」是否为原目录，再检查已有形象、桌宠和接入状态。接入若提示缺失，可使用「重新安装接入」，随后完成宿主重载和 Hooks 审核。

更换程序安装位置前请记录并备份数据，不要直接拖动程序文件夹。仅想把形象和项目放到其他磁盘时，优先使用应用内「修改目录」，见 [数据与内容目录](desktop-installation.md#数据与内容目录)。

## 从旧版插件迁移

旧版完整 Codex/DSH 插件和 Cursor VSIX 不属于当前桌面安装方式。曾使用旧版时，请在对应宿主中停用或卸载旧插件，确认旧进程退出，再安装桌面版并从工作台添加接入。

请保留旧数据备份，先确认桌面版中的形象和设置，再清理旧文件。当前安装和卸载流程不会替你清空未知插件目录或宿主信任记录。

## 排查与反馈

工作台能打开时，可在「应用设置 → 版本与诊断」导出诊断。安装失败日志位于 `%TEMP%/LingPet-Setup-Logs`，失败提示会给出具体路径。

反馈时附上灵伴版本、Windows 与宿主版本、复现步骤和相关日志；分享前检查并移除密钥、凭证及其他敏感内容。更多排查步骤见 [快速开始](getting-started.md#5-日常使用与排查)。
