# 灵伴集市

桌面端 0.5.0 的「已安装与版本」会按作者仓库及作品 ID 检查已审核的新版本，下载仅加入形象库，旧版本保留；选择版本可切换／回退当前桌宠。离线时仍可使用已安装版本。相同素材的不同版本可共用文件并保留版本记录。

分享包仍要求八种会话状态，可在 `manifest.clips` 附带单次播放的 `click`、`pet`，路径为 `sprites/click.png`、`sprites/pet.png`，原图使用 `original/` 前缀，清单尺寸与状态动作一致。含互动的包声明 `minAppVersion: "0.5.0"`，导入与再次导出保留互动。市场服务器需同步升级兼容校验后才能审核这一最低版本的投稿。

市场审核范围为这里展示的名称、介绍、封面及授权声明。下载包由作者通过 GitHub 维护，可能在投稿后发生变化；市场不对下载包的全部内容作审核保证。投稿哈希仅供记录。

工作台侧边栏「桌宠市场」是内置市场页面，可搜索审核后的作品、查看封面、查看封面和作品介绍，选择新增一只桌宠、应用到当前桌宠或仅加入形象库。客户端从作者的 GitHub Release 下载 `.petpack`，通过包格式、路径、资源大小和作品 ID、版本检查后安装，不强制比对投稿时的文件哈希或大小。应用到当前桌宠会保留其位置和跟随设置。已安装素材可离线播放；网站未部署或不可用时仍可导入本地分享包。

作者在「更多操作 → 导出分享包」填写作品 ID、名称、版本、作者和授权声明，将生成的文件上传自己公开 GitHub 仓库的正式 Release，然后在工作台「桌宠市场 → 投稿作品」或网页市场免登录投稿，填写仓库、标签与附件名。提交后请保存编号和私密凭证，用于查询进度；浏览器尝试保存最近50份凭证，也可下载备份。每个版本独立审核，同一作品发布更新需增加版本号。请只发布有权分发的作品；创作项目、提示词、密钥和本机设置不会进入分享包。

管理员使用独立账号密码登录后台，可查看作品介绍、授权与封面（历史投稿保留动作预览），再通过、驳回或下架。服务器保留版本、哈希和审核记录；大文件由作者托管。新版投稿不下载原始包，只保存数据库与封面快照；历史投稿的动作预览继续可用。GitHub 上的公开附件可在市场之外访问。

默认市场地址为 `https://lingpet.fourzkw.top`。服务器使用 Go、bbolt、systemd 和 Nginx，无需 Docker。源代码中的 `market/README.md` 包含 DNS、管理员密码配置、部署、备份与限制说明，无需注册 GitHub OAuth App。Linux amd64（x86_64）的独立部署包包含二进制及配置模板；服务器无需安装 Go。

首版按已审核版本展示，暂不提供评分、评论、付费、镜像或自动更新。GitHub 附件删除后会导致下载失败；作者替换同一标签下的附件后，客户端可安装符合安全限制且作品 ID、版本匹配的包，不要求与投稿文件完全一致。市场展示信息与预览保持审核时的快照，更新展示内容需重新投稿审核。
个人和组织仓库均可推荐，提交链接不代表作者身份，需管理员核查来源和授权。市场服务版本独立为0.4.7，兼容现有0.4.1桌面客户端。凭证遗失无法按账号找回，首版撤回需联系管理员。



首次部署默认账号为 admin，服务自动生成本次部署专属的初始密码，保存在数据目录的 initial-admin-password.txt。首次登录必须改密；修改完成后初始文件会删除。密码哈希保存在 market.db，更新程序时保留数据目录即可继续使用原密码。账号和可选密码哈希环境变量只用于首次初始化；从旧版升级会导入原配置中的密码哈希。


管理员可通过网页右上角「修改用户名」更换登录名，需验证当前密码；新用户名不含空白，最多64个字符。更名后密码保持不变、其他旧会话失效，当前会话继续使用。后续重启和升级保留数据目录即可保留新用户名，首次初始化的用户名环境变量不会覆盖数据库。



管理后台包含数据概览、作品审核、安装包管理和操作记录。可上传对应客户端的安装包，审核包内版本后保存为待发布版本，再发布、下架或切回历史版本；可查看访问和下载请求统计，并导出CSV。上传的包、发布状态和统计保存在服务器数据目录，升级时保留该目录。大文件上传需合并新版Nginx上传配置，详见服务部署说明。


桌面客户端0.4.4新增面板内「发现桌宠、投稿作品、查询投稿」页面。动作预览使用服务端缩小后的图集，不操作真实桌宠；安装时使用完整素材。选择左侧桌宠或「返回工作台」可回到外观与跟随设置。默认新增实例，也可应用到当前实例或只加入形象库。凭证以私有文件保存在本机数据目录的 market-receipts.json，最多100条，另可通过「保存凭证文件」备份；网页浏览器的50条记录与本机记录独立。新客户端兼容现有市场0.4.7，无需更新服务端。


连接设置支持明确指定 HTTP 或 HTTPS 根地址。默认地址使用 HTTPS；当前服务器的 HTTP 地址为 http://lingpet.fourzkw.top，HTTPS 证书域名需要与站点匹配。若使用当前 HTTP 站点，可在「连接设置」输入该 HTTP 根地址。不会自动跳过证书校验或在请求失败时降级连接。


## 轻量仓库投稿

公开仓库同一 Release 标签下必须包含 pet.json（作品 ID、版本、名称、作者、授权和介绍，格式与分享包元数据相同）及 previews/cover.png（8bit RGBA PNG，最多1 MiB、1024×1024像素总量）。服务只访问 GitHub API 获取展示资料和附件信息，不下载完整 .petpack。客户端安装时才从 GitHub 下载分享包。管理员查看展示资料后通过或驳回；校验失败可点击“重试读取资料”。新投稿展示封面，历史动画预览仍保留。


## GitHub 访问加速

默认依次尝试 direct（GitHub 直连）、gh-proxy（https://gh-proxy.com/）、ghfast（https://ghfast.top/），无需安装本地代理。每条线路单次请求最多20秒，返回网络错误、非成功状态或无效 JSON 后尝试下一条；直连 GitHub 返回404时直接提示缺少仓库、标签或文件。第三方服务对 API 的支持和可用性可能变化，所有线路失败时保留明确错误，可在后台重试。

可在 /etc/lingpet-market.env 设置 LINGPET_GITHUB_ROUTES=gh-proxy,direct,ghfast 调整顺序；设置为 direct 关闭中转。保存后执行 sudo systemctl restart lingpet-market。默认不配置也生效。GITHUB_TOKEN 仅发送给直连 GitHub API，中转不携带认证信息；限制 HTTPS、公网目标和已知重定向域名，保留响应体积限制。这里只读取公开仓库介绍、封面与附件元数据，不克隆仓库，也不下载完整桌宠包。


客户端0.4.5修复轻量投稿缺少审核哈希时无法安装的问题，并在作品详情提供 GitHub 仓库和对应 Release 入口。使用旧客户端遇到“无效审核记录”时需更新客户端并完全退出后重新启动；仅更新服务端不能移除旧客户端的强制校验。市场服务0.4.10在审核列表和作品详情提供仓库及 Release 链接。


客户端0.4.7按完整动作素材及播放配置识别重复形象：同一形象从本地导入后再从市场安装会复用已有记录，作者、授权、介绍或ZIP压缩变化不会新增相同形象。历史重复记录在形象库中合并展示并迁移实例引用，保留原素材和创作项目；同名但动作素材或时序不同的形象不合并。


网页与桌面市场的每个线上桌宠卡片及详情均展示下载量和 Star。下载量来自对应 Release 的分享包附件（当前版本），Star 为作者 GitHub 仓库的获星数。服务端缓存15分钟；读取失败时保留上次成功数据，1分钟后允许重试，无历史数据时显示“暂不可用”。旧服务端没有统计字段时客户端同样显示“暂不可用”。
