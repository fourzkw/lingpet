# Claude complete actions v2

All eight states now use authored 128×128 pose sequences. Rows of `atlas.png` are waving, continuous typing, jump, idle, thinking, approval, error, sleep. Each row has eight poses; the atlas is 1024×1024 RGBA. The original character references and v1 are preserved.

The typing row was regenerated with both hands on or immediately above the keys throughout. All upper 64 pixel rows are locked to the first frame, so the head and upper torso remain stationary and no high-hand gesture can enter this clip. Only the lower hands and key region animate. It loops continuously without a dramatic pause or raised hand.

- Idle: observe left/right, shift a foot, blink, settle.
- Thinking: look aside, lean and scratch the temple; the settled gesture repeats after its entrance.
- Approval: grasp and raise a golden check shield, then hold it, gesture and blink. The shield-raising entrance plays only once.
- Error: startle, flinch, shake, slump and recover. The final concerned pose holds; the startling entrance does not repeat.
- Sleep: become drowsy, fold feet, lower arms and settle with eyes closed. Only the last four closed-eye resting poses repeat; it never stands up on every cycle.
- Waving and jump retain the v1 pose artwork. Jump plays once and holds its landed recovery frame.

The six new raw sheets were generated by the built-in **image_gen** tool with the approved v1 character sheet and original Claude image as references. Exact prompts are in `prompts.json`. `scripts/build-claude-actions-v2.py` cleans stray components, registers a constant camera scale per action and the foot/prop baseline, quantizes colors and enforces binary alpha. `registration.json` records the packing parameters.

`desktop/claude-actions.js` defines per-frame durations and optional `loopFrom` entry indices. Body motion uses the actual pose frames; independently timed dots, shield glints, sweat and sleep marks form the effect layer. The renderer never stretches or deforms these Claude body frames. DeepSeek is unchanged.
