# 基础形象与动作创作

## 输入与造型

将用户需求整理成以下可独立修改的字段：

- 身份：发型、眼睛、服饰、耳/角/翼/尾巴、重要饰物等必须保留的特征。
- 风格：Q 版、像素、日系插画或用户自定画风；不要擅自换成另一种。
- 比例与姿势：头身比例、站/坐/其他姿势、四肢和脚向、视角；未指定时选择适合角色的自然姿态，不默认团子坐姿。
- 构图：完整角色、清晰轮廓、动作安全边距、后续视频适用的画幅。
- 输出：是否需要动作、哪些动作、原图/像素/两者；保留还是替换现有形象。

参考图的身份、风格、姿势作用分别记录。原人物比例与用户要求的 Q 版比例冲突时，以用户的重设计要求为准，不能把“参考原图”理解为必须保留成人比例。

### 基础图提示词结构

按任务需要填入这些信息，不原样提交未填写的模板：

> 为桌宠生成单张完整基础立绘。人物身份与保留特征；各参考图的作用；用户指定画风与比例；明确姿势、四肢和脚向；服饰与色彩；相机和构图；透明背景或明确后处理方案；需要避免的具体变化。

制作视频时先使用一张确定的立绘，而不是把八种姿态拼成首帧。需要像素输出时，通常保留细节生成视频再统一像素化；若用户明确要求原生像素视频，以其选择为准。

### 检查与反馈

同时检查大图和目标显示尺寸：身份可辨、眼睛与服饰正确、肢体连接自然、无缺失/多余肢体、配件不遮挡关键部位、完整轮廓不被裁切。

用户反馈具体问题时，更新对应字段而不是不断堆叠矛盾要求。例如“不要内八”应明确膝盖、脚踝、脚尖方向一致，双脚平行或用户认可的轻微外开；检查实际图像，不能因提示词写了该要求就认定结果满足。站/坐选择以该项目要求为准，不把一种修正通用于所有角色。

默认只改变用户指出的部分，保留已确定的身份和风格。若姿势必须整体改变才能解决问题，应明确说明这个选择，不暗中修改人物比例、服装或角色。保留旧候选并生成新版本，不覆盖输入文件。

## 动作设计

### 先分析角色，再映射状态

观看选定基础图并读取设定，区分图中可见特征、用户明确设定和待验证的创作推断。提取能影响动作的特征：身份/性格、肢体与附肢、服饰和活动空间、已有道具、力量或职业主题。无法从图片判断的能力不要当作既定设定；可据用户授权提出适合的表现方案。

每个状态先回答“这个角色会如何表达这一状态”，再写提示词。状态决定行为目的，角色决定表现方式。例如书卷气的龙灵可以执笔写卷，机械角色可以检修浮空组件；两者都能表达 `working`。不把一个角色的卷轴、毛笔或魔法套给所有角色，也不要求八个状态都换一件新道具。简单呼吸、眼神和身体动作同样可以体现身份。

在项目中保存精简动作方案，包含：状态意图、采用的角色特征、道具/交互、进入→持续→结束分镜、各段时间、生成总时长/帧数、循环策略与视觉检查点。先向用户简要展示方案；用户已明确指定或授权连续完成时直接按方案试片，不增加重复确认。

以下是当前桌宠常用状态的语义，实际所需状态以用户需求和播放器为准：

| 状态 | 进入动作 | 持续/结束要求 |
|---|---|---|
| `idle` | 自然待机 | 呼吸、短促自然眨眼、轻微发尾变化；循环自然 |
| `thinking` | 托腮、轻微头部变化等 | 进入后保持思考，不反复重演整段起手 |
| `working` | 进入符合角色的执行姿势，必要时出现道具 | 持续且可辨识的操作；肢体与道具接触连贯，避免无关挥手或头身晃动 |
| `input` | 小幅招手/邀请 | 明确等待用户，循环或回到起姿 |
| `approval` | 展示许可请求姿态或合适道具 | 进入后等待，道具不要反复出现/消失 |
| `done` | 短庆祝 | 播放一次，恢复并保持结束姿势 |
| `error` | 短暂惊讶或担忧 | 播放一次后平稳恢复，不持续抽搐 |
| `sleep` | 放松闭眼 | 进入后保持闭眼，不能循环回睁眼入睡 |

视频提示词应组合“冻结的身份设定＋当前动作＋相机/构图约束＋用户提出的特定限制”。不是所有角色都需要键盘、盾牌、跳跃或翅膀动作，道具和动作以需求为准。

### 按内容确定时长与循环

先估计进入、持续和结束各段需要的时间，再选工作流支持的帧数。呼吸或简短反应无需凑长；道具出现、拿取、操作等多阶段动作应留足可读时间，必要时简化分镜。工具默认约五秒只是省略参数时的技术默认值，不能作为所有动作的设计时长。生成时长也不等于状态停留时间：桌宠可在持续段循环，等待真实会话状态改变。

按当前工作流将目标秒数换算到合法帧数，并记录实际值，详见 [创作工具](tools.md)。不要通过统一改播放速度来凑时长。较长片段需一并检查后处理的采样帧上限，避免生成完成后无法导出。

带道具的持续状态通常采用“进入段只播一次＋持续段循环”：从姿态和道具均稳定的位置设置 `loopFrom`，不让卷轴在每次循环重新出现、毛笔反复凭空换手。完成/异常通常单次播放并保持末帧；睡眠持续段保持闭眼。按真实输出选循环点，不能只按分镜预估。

### 示例：青墨龙灵的执行工具动作

用户提出的 `working` 设计可表现为：虚空中浮现一张竖直卷轴，龙灵执起毛笔，在卷面上书写。先依据实际形象确认执笔手、衣袖/龙尾活动范围，给卷轴留出空间，避免遮住脸、切掉卷轴或让笔穿过手指。

可先试约八秒：0～1.5 秒卷轴在角色身侧浮现展开，1.5～2.5 秒执笔并靠近卷面，2.5～8 秒保持卷轴稳定、手腕小幅书写。当前 24fps 工作流的 192 帧约为八秒；这是试片设计，不是该角色所有动作的固定参数。循环仅取稳定书写段，检查笔尖接触、前后遮挡、墨迹连续性和接缝；避免墨迹每次循环突然清空或不断叠满。生成结果若不能稳定呈现完整取笔过程，可按用户意图简化为执笔起姿，不能悄悄改成键盘动作。

先试这一关键交互，而不是仅验证空闲后就批量生成所有持物动作。卷轴方向、出现方式和书写动作来自本例的用户要求，不作为其他角色的默认设定。

固定镜头、人物尺度、画幅、朝向和足底基线能减少桌面播放漂移。站立角色通常保持脚底稳定；用户要求走路、跳跃等动作时不得机械锁脚。

闭合动作可在支持的工作流中约束首尾图。持续工作、持物等待、睡眠不宜强迫最后回到中性睁眼姿势，应规划进入段与持续段。是否支持首尾帧以及帧数要求需读取实际工作流。

## 试片与扩展

先检查一个动作的首帧、中间帧、末帧，以及实际播放：身份/比例是否漂移、眼睛与嘴是否异常、肢体与道具是否连贯、画面是否平移缩放、背景是否稳定。

样片合格后使用同一基础图版本扩展其他动作。改变相同角色的基础图时，旧版本视频不自动成为新版本的一部分；已生成素材可以保留归档，不能静默混入。

反向播放仅适合可逆的稳定片段，例如轻呼吸，不适合眨眼、打字语义不连贯的动作或道具出现过程。必须实际检查循环接缝，不能仅依赖“首尾相同”的提示词。
