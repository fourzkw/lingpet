# 能力发现与环境适配

## 真实能力与调用位置

本 Skill 为当前桌宠插件提供创作指导，不代替工具实现。发现当前宿主实际提供的工具或资源，并读取输入/输出定义，不编造名称、文件 ID 或成功结果。

当前源码提供统一创作工具，支持图像 API、Seedance、MiniMax API，以及 ComfyUI Qwen-Image 2.1 图像生成/编辑、H3 视频、项目/任务、资源预览、后处理及形象导入。真实工具输入与限制见 [创作工具](tools.md)。旧安装版本可能仅提供启停管理，调用前仍须发现能力。仓库原有 Python 人物脚本仍是开发用实现，不属于这些公共接口。

所需操作意图如下；对应真实工具见创作工具文档：

| 操作 | 关键输入 | 应确认的返回信息 |
|---|---|---|
| 检查环境 | 后端配置或连接 ID | 可达性、工作流、节点、模型映射、缺失依赖 |
| 导入参考素材 | 宿主上传文件/资源 ID | 可读文件 ID、尺寸、类型、内容哈希 |
| 生成基础图 | 提示词、可选参考图、风格、工作流绑定 | 项目版本、任务 ID、状态、候选资源 |
| 生成动作视频 | 确定的基础图 ID、动作说明、工作流参数 | 任务 ID、所有权、输入版本、状态 |
| 查询/取消任务 | 项目与所属任务 ID | 实际执行状态、错误、输出或取消结果 |
| 后处理/预览 | 视频 ID、尺寸、透明度、风格、循环规则 | 预览、图集、时序、验证结果 |
| 导入桌宠形象 | 资源清单、目标角色、新形象 ID | 导入结果、实际可用版本；激活单独说明 |

用户本机的插件后端读取应用配置，连接云端 API 或 ComfyUI。云端 AI 所处环境的 `127.0.0.1` 不代表用户本机；不能要求其绕过插件直接访问用户的环回地址。宿主支持本地执行时可使用该能力，但仍需读取实际配置。文件优先使用宿主支持的上传/资源 ID，不假定 AI 与用户共享文件系统。

## 配置与依赖

记录连接地址、工作流 ID/版本和参数绑定；认证信息由宿主的配置机制保存，不写进提示词、Skill 或可分享项目文件。

图像生成和视频生成分别检测：

- 基础图需要文生图或参考图生图能力。用户已提供合适基础图时可以跳过重新生成。
- 生图与视频分别遵循应用设置中的已启用优先级；通过 `board_pet_generation_settings` 检查，详情见 [生成服务与优先级](generation-services.md)。只有用户明确指定时覆盖选择。
- 文本聊天模型不等于图像模型。没有可用图像后端时说明缺失能力；不承诺其他用户拥有 AI 内置的图像生成工具。
- ComfyUI 工作流依赖具体节点、模型类型和输入结构。检查实际安装节点及模型，不自动用同名或近似模型替换。
- 预设缺失时列出准确缺项；不要未经用户请求下载安装大型模型、安装自定义节点或切换到付费云服务。

本项目曾验证的本机 H3 配方：384×384、124 帧、24fps、20 steps、`res_multistep` 采样器、`simple` 调度器；使用 MiniMax H3 的扩散模型、对应文本编码器和视频 VAE。它是一个已验证实例，不是所有模型或硬件的统一要求。迁移时重新检查节点定义、模型映射、分辨率和帧数约束，不能仅复制机器上的模型文件名。

若后端使用 ComfyUI 原生 HTTP API，本项目已采用的操作包括：上传图片 `/upload/image`、提交 `/prompt`、查询 `/queue` 和 `/history/{prompt_id}`、读取输出 `/view`。可通过节点信息检查输入定义。优先由插件工具包装这些操作；Skill 本身不提供网络访问能力。

## 任务生命周期

提交前保存基础图哈希、工作流修订、实际参数和所属项目。返回任务 ID 后写入记录；网络超时不代表未提交，先查询可能已接受的任务，避免盲目重提。

成功条件是执行成功、输出存在且可读；排队、进度达到采样步数或 HTTP 请求成功都不能代替它。失败时保存节点和错误，修正具体原因后进行有限重试；相同错误重复发生时停止该动作，不无界重试。

用户要求停止时：停止本项目批次调度；取消本项目尚未执行的任务；只有当前运行 ID 确认属于本项目时才中断该任务。若后端只有全局中断接口，先核对当前 ID，不中断其他项目；保留输出并记录未完成项。恢复必须来自用户后续明确指令，不能把继续讨论方案当作恢复执行。

## 随当前插件分发

分发时保持 `SKILL.md`、`agents/` 和 `references/` 的相对目录关系。插件安装包必须实际包含整个 Skill 目录；仅放在开发仓库内不等于已经分发。

由各宿主适配层按其支持的机制注册/发现 Skill；不支持 Skill 的宿主可以读取同一说明或由插件资源入口提供指引。复制目录不能保证所有 AI 自动发现。宿主元数据 `agents/openai.yaml` 只是可选展示信息，不是生成工具注册。

构建脚本已复制 Skill 和运行工具到安装包；是否已更新某台机器上的安装，以及该宿主是否发现 Skill，必须分别检查。不自动安装或配置 ComfyUI、模型或自定义节点。
