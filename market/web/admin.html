客户端下载

灵伴统一使用 Windows 桌面安装程序，安装后在应用内接入 Cursor、Codex 或 DSH。

安装程序发布至 fourzkw/lingpet 的 GitHub Release；官网与桌面端的下载按钮会直接解析到最新安装包文件，用户无需打开 Release 页面。服务器只解析地址，不中转、不存储安装包。

查看最新 Release ↗ 管理 GitHub 版本 ↗

请在正式 Release 中上传 LingPet-Setup-版本号.exe 和 release.json（含 version、setup、sha256、bytes），桌面端会据此校验安装包并展示更新说明。官网统计的是下载入口点击，文件流量由 GitHub 承担。
