01 下载桌面安装程序

点击「下载 Windows 版」，浏览器会直接开始下载 LingPet-Setup 安装程序，无需前往 GitHub 页面；下载完成后运行安装程序即可。

02 在灵伴内接入 Agent

打开工作台的「Agent 接入」，选择 Cursor、Codex 或 DSH，点击「安装接入插件」，按提示完成配置。

03 开始你的桌面陪伴

按提示重新打开对应工具，完成所需的权限确认，再发送一条真实 Agent 消息验证连接。回到灵伴选择形象并显示桌宠。
