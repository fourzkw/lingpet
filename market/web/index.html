A FEW SIMPLE STEPS

装好插件，
迎接你的灵伴。

安装前运行 node --version，确认 Node.js ≥22.19；安装后重启宿主。
首次启动若缺少运行时需联网准备，内置形象无需模型密钥。
打开工作台顶部引导，选择来源、显示桌宠，再发送真实 Agent 消息完成接入检查。

查看完整安装与排查指引 ↗
01 DSH · 安装 .tgz 插件包

下载 DSH 安装包后，在 DSH 的插件管理中选择本地文件安装；运行中的实例推荐从应用内安装，以匹配当前配置。

02 Cursor · 安装 .vsix 扩展

下载 Cursor 安装包，在扩展面板菜单选择「从 VSIX 安装」，安装后重载窗口，在侧边栏打开「灵伴桌宠」。

03 Codex · 添加本地插件市场

下载并解压 Codex 包，将解压目录添加为本地插件市场，再安装灵伴。下面以解压到 D:/LingPet/codex 为例：

codex plugin marketplace add "D:/LingPet/codex"
codex plugin add board-pet@board-pet-local

安装后重启客户端，并在支持的 Hooks 审核入口中信任插件事件。详细说明见安装包内 README。
