# 方案 C · 纸感手账（PAPER JOURNAL）

## 一句话主张

**桌面是一本摊开的手账，桌宠是贴在页边的小贴纸——状态用便签、印章、荧光笔与和纸胶带说话，而不是用一块后台面板。**

## 关键词

暖纸 · 墨字 · 朱砂印章 · 竹青 · 便签 · 和纸胶带 · 手账横线 · 纸边投影 · 手作感 · 白天可读

---

## 为什么适合灵伴

1. **「贴纸」正好解释了透明窗口的技术事实。** 桌宠是 512×512 真透明浮层，周围不能铺底色——贴纸是最自然的类比：纸片只包住角色和它当前要说的那一两句话，其余地方透出用户的桌面。这也顺手解决了「透明窗口里放什么容器」的问题：不放假面板，只放纸片。
2. **手账 = 陪伴感 + 记录感，而不是工具感。** 灵伴的核心价值是「陪你把手上的活干完」，不是又一个监控面板。手账的语汇（今日、批注、划重点、贴一张）天生属于陪伴，而仪表盘属于运维。四个方向里只有本方案把「陪伴」放在第一层。
3. **浅色是四个方向里缺的一块拼图，而且有真实需求。** 白天用电脑、桌面偏浅、DSH / Cursor 宿主切到浅色主题时，全深色浮层会显得突兀。本方案以暖纸为默认，同时给出深色变体（夜间桌面、深色宿主注入），不是「只做一版好看」。
4. **一只手账本天然统一五个表面。** 桌宠浮层=贴纸，快捷控制=便签条，工作台=摊开的一页，市场=作品贴纸册，DSH 面板=插在宿主页里的一页纸。信息架构与别的方向一致，差异全部来自造型语言——便于横向对比与灰度切换。
5. **性能与实现成本低。** 纸感全部由 CSS 完成：纸纹=两组极低对比 repeating 噪点、点阵=1 个 radial-gradient、横线=repeating-linear-gradient、胶带=半透明色块 + 4~8° rotate、印章=1px 圆环描边 + 两个汉字。没有位图纹理、没有 canvas 阴影、没有运行时依赖，桌宠窗口额外开销 < 1KB CSS。

### 字体与字阶

- 标题 / 大数字：**Noto Serif SC**（思源宋体，书卷气，纸张上的印刷感）；回退 `SimSun`。
- 正文 / UI：**Microsoft YaHei**（本机已装，不联网加载字体）；英文回退 Segoe UI。
- 数字 / 代码 / token：**Consolas**。
- 手写批注：**STKaiti / KaiTi**，只允许出现在「批注 / 一句话」位置，正文与按钮禁用。

### 形状与描边

- 圆角档位：note **2px** / control **3px** / card **3~4px** / window **6px** / pill **999px（只用于开关与胶囊）**。最大圆角 6px——手账本没有大圆角。
- 描边：1px 为默认（纸边即描边）；1.5px 只用于强调框（选中、当前）；2px 只用于印章。
- 分隔线：实线 1px `#DCCFB6`；手账线用虚线 `2-4` 或 `repeating-linear-gradient` 横线。
- 纸边投影 = 多层柔和 + 1px 内高光（`rgba(255,255,255,.45)` 内描边），靠「两层以内的投影 + 内高光」表达纸张厚度，而不是大阴影。

### 光影与纹理

- 投影只有三档：贴纸影 `0 3px 7px rgba(58,43,24,.28)`、卡片影 `0 1px 1px + 0 5px 14px rgba(92,70,38,.16/.10)`、浮层影 `0 2px 2px + 0 12px 20px`。
- 纹理四种，全部 CSS：纸纹（极低对比噪点 pattern）、点阵（26px 网格 1px 点）、手账横线（28px 行距 1px 线）、和纸斜纹（45° 半透明条）。
- 桌宠窗口内**禁止** `backdrop-filter`、大面积渐变、整块暗色遮罩；透明就是透明，只有纸片有底色。
- 接触阴影：角色脚下垫一枚椭圆软影（112×15 + blur 4px，opacity .26），贴图本身不裁边，窗口整体移动时影子跟着走。
- **深色桌面**：桌面可以暗（`#191410`），纸片仍是 `#FCF7EC` 不透明——只换桌面、不换纸，分层靠 1px 暖白内描边 + 两层纸影（板图 §01 右下给了 300×200 的「夜读灯下」对照小样）。

### 动效语言

| 动效 | 规格 | 触发 |
| --- | --- | --- |
| 便签滑入 | 220ms `cubic-bezier(.2,.7,.2,1)`，translateY 8→0 + opacity 0→1 | 状态切换 / 气泡出现 |
| 印章落下 | 320ms，scale 1.3→1 + opacity 0→.9 | 完成 / 等待确认 |
| 纸片轻摆 | 3.2s ease-in-out 循环，rotate −1.5°→1.5° | 仅 thinking |
| 光晕呼吸 | 2.4s ease-in-out，opacity .35→.7 | working |
| 错误抖动 | 180ms × 2，translateX ±2px | error |

必须的降级：`@media (prefers-reduced-motion: reduce)` 下所有位移 / 旋转 / 缩放改为 opacity 直切、时长 1ms；呼吸与轻摆直接关闭（保留静态差异）。悬停与按下只用背景 / 边框颜色，不做位移动画，避免桌宠窗口抖动。

### 图标与图形

状态图形只做六种，全部能用 CSS/SVG 12 行内画完：**点 / 虚线圈 / 波浪 / 方章 / 折角 / 对勾**。映射：空闲·休眠=点，思考中·等待输入=虚线圈，执行工具=波浪，等待确认=方章，完成=对勾，错误=折角。不引入第三方图标库。手绘强调元素（荧光笔 / 胶带 / 印章）**每屏最多 1 处**，其余保持安静。

## 各表面设计要点

### 桌宠浮层（512×512 透明）

- 角色居中偏下，高约 300~340；窗口四角真透明，四角括号只是板图示意，产品里没有。
- 状态 = 白纸片 + 左缘一条状态色 + 等宽耗时，贴在角色左下角；不靠 6px 圆点换色。
- 气泡 = 纸片 + 手绘小尾巴，正文宋体、落款等宽；4.2s 后自动收进状态便签，避免长期遮挡角色。
- hover 浮出 1 条纸片操作条：⚙ 工作台 / ⇄ 换角色 / − 隐藏；平时不占屏幕。
- 接触阴影只跟贴图走；窗口整体移动时不拖底色。

### 快捷控制（右键弹层，300~340 宽）

- 一张便签纸，顶部一条和纸胶带。列表 4 只桌宠：缩略图 + 名称 + `Claude · 像素 · 已显示`，当前项白底 + 左朱砂条 + 「当前」+ 圆章对勾。
- 下方纸片开关组：显示桌宠 / 大小（3 档滑杆 + px 读数）/ 会话跟随；底「进入工作台」朱砂实心按钮 + 「修改后自动保存 · 仅本机」。
- 4 只桌宠可能更多：列表区固定高度 + 右侧滚动轨 + 底部渐隐，暗示可滚动；弹层内容高 ≤ 屏幕高 − 80。
- 深色桌面下纸片仍是暖白（见「夜读灯下」），弹层不随桌面变暗。

### 工作台（1520×940 等比）

- 左边栏 268：品牌「灵 / 灵伴 LINGPET」、导航（桌宠工作台 / 桌宠市场）、我的桌宠 4 项（缩略图 + 名称 + `Claude · 像素 · 已显示` + 删除）、底部虚线「＋ 新增桌宠」+ 两行小字。
- 主区：kicker「灵伴 / 桌宠管理」+ h1 桌宠工作台 + 副标题 + 右上连接胶囊「● Codex / Cursor / DSH 已连接 · 3」。
- 实时预览：舞台（点阵纸 + 四角括号）+ 角色大图 + 状态便签 + 会话行 + 「隐藏桌宠」主按钮 + 最近活动（3 条，含状态色点）。
- 右侧：tab（外观与显示 / 会话跟随）→ 选择角色（DeepSeek 选中，朱砂描边 + 对勾）→ 选择形象（已保存徽章 + 鲸鱼娘 + 原图/像素）→ 显示与大小（192 px 滑杆 + 两个开关）→ 添加形象（虚线拖入区 + 骨架屏「读取中…」，同时给出空态与加载态暗示）。
- 视觉焦点只有一个：实时预览面板；其余卡片降为纸白 + 细线。

### 市场（~520 高）

- 标题「桌宠市场」+ 副标题；右侧「导入本地包」+「安装方式 / 当前：默认桌宠 ▾」。
- tabs：发现桌宠（荧光笔底线）/ 投稿作品 / 查询投稿；搜索框「搜索桌宠」+「作者或介绍」。
- 4 张作品卡是主角：封面 4:3 + 一条胶带 + 角色图 + 名称 / 作者 / 下载数 / 安装按钮；卡片之间靠纸边与白度分层，不靠重投影。

### DSH 设置页注入面板（~460 宽）

- 标题「你的会话伙伴」；状态卡「桌宠运行状态」（绿点 + 说明 + 启动桌宠 / 关闭全部 / 打开工作台）+「会话偏好」（自动启动桌宠 / 显示子 Agent / 恢复继承配置）。
- **必须跟随宿主深浅**：所有底色 = `color-mix(in srgb, currentColor 6%~12%, transparent)`，文字继承 `color: inherit`，强调色回退 `--lp-accent`。面板不写死纸色，只保留手账的「线 / 印章 / 描边」语言；深色宿主下用一个 1px 暖白内描边和纸片语义，而不是整块米色。
- 浅色宿主时同上，纸感降到「细线与印章」层，不用大面积米色块——这是「浅色一屏米色块」的反面约束。

### 市场网站首页（~640 宽浏览器视口）

- 导航（灵 / 灵伴 + 桌宠市场 / 投稿作品 / 文档 + 下载应用）→ hero「把桌宠贴到桌面上」+ 两行说明 + 浏览桌宠 / 投稿作品 → 右侧一张贴纸插画（胶带 + 角色）→ 3 张作品卡 + 底部「共 12 只桌宠 · 查看全部 →」。
- 与桌面端共用 token 与作品卡组件，站点只是同一套纸放大。

### 需要新增的类

`.lp-paper`（纸片：底 + 1px 线 + 内高光 + 卡片影）、`.lp-paper--float`（浮层影）、`.lp-tape`（伪元素斜纹 + rotate）、`.lp-stamp`（圆环描边 + 两字，`--lp-stamp-color`）、`.lp-sticky`（便签 + 左缘状态条）、`.lp-rules`（手账横线背景）、`.lp-dotgrid`（点阵背景）、`.lp-index`（页边编号 01…06）、`.lp-tail`（气泡尾巴，用两个伪元素叠出纸片缺口）。全部纯 CSS，无图片资源。

纸片的默认配方（直接抄，§01「白壁纸对照」小样验证过）：

```css
.lp-paper {
  background: #FCF7EC;
  border: var(--lp-paper-edge);              /* 1px solid #DCCFB6 */
  border-radius: 3px;
  box-shadow: var(--lp-paper-shadow);        /* inset 0 0 0 1px #FFFDF7 + 两层纸影 */
}
/* 壁纸接近纯白（#F7F1E4 及更白）时，描边加粗一档，内高光不动；这是唯一需要的降级 */
@media (prefers-contrast: more), (prefers-color-scheme: light) {
  .lp-paper--float { border-width: 1.2px; }
}
```

### 性能与实现注意

1. 桌宠窗口只有 512×512，避免常驻 `filter: blur()`、`backdrop-filter` 与大尺寸 `box-shadow`；阴影用 `filter: drop-shadow()` 跟贴图轮廓走，绝不用 `box-shadow` 画矩形边界。
2. 纸纹 / 点阵用 `background-image: repeating-*` 或小尺寸 `radial-gradient`，不用位图；`background-attachment: fixed` 禁用。
3. 动效只跑 `transform` / `opacity`；thinking 的轻摆与 working 的光晕在窗口隐藏（`document.hidden` 或窗口不可见）时暂停，避免常驻 GPU 占用。
4. 滚动区（快捷控制列表、市场列表）用 `overflow: auto` + 渐隐遮罩，不嵌套滚动。
5. 对比度：正文 ≥ 6:1、次要与按钮文字 ≥ 4.5:1、8 个状态色在纸底上全部 ≥ 4.5:1（已核算）；`prefers-contrast: more` 下描边加粗到 1.5px 且 `--lp-faint` 提到 `#6F6353`。

## 取舍与风险

1. **浅色 + 透明窗口容易「糊」。** 浅色纸片在浅色壁纸上边界会消失。对策：纸片 = `1px #DCCFB6` 描边 + `inset 0 0 0 1px #FFFDF7` 内高光 + 两层纸影；桌宠窗口只让纸片有底色，其余真透明；状态便签与气泡不叠在角色头部。**已在板图 §01 做白壁纸对照实证**：底色换成 `#F7F1E4`（比纸片 #FCF7EC 还白一档）后，只用描边的 A 边缘发虚，加内高光 + 投影的 B 边界仍清晰——所以浮层纸片默认用 B 配方（`--lp-paper-shadow`），只有贴图本体不加内描边（会破坏像素边缘）。残余风险：纯白壁纸（#FFFFFF）下把描边加到 1.2px（`border.whitePaperFallback`），内高光不变。
2. **手账元素贴太满会变廉价。** 荧光笔 / 胶带 / 印章每屏只允许 1 处，其余靠横线、留白、纸白分层说话；板图里 §01 用一个便签、§02 用一条胶带、§03 只用页边编号，都是刻意的额度控制。
3. **DSH 面板是宿主页面里的客人。** 写死米色会在深色宿主里变成一块亮斑。对策：面板底色全部由 `color-mix(in srgb, currentColor …)` 派生，纸感只保留「线 + 印章 + 内描边」，强调色回退 `--lp-accent`（可被宿主覆盖）。这条是硬约束，板图 §05 给了深/浅两版对照。
4. **宋体做标题有「老气」风险。** 只在大标题与数字上用宋体，正文与按钮全部黑体；楷体只做批注，且数量受限。若评审觉得书卷气过重，退化路径是把 display 换成 Noto Sans SC 700，其余不变。
5. **浅色在夜间桌面会刺眼。** 深色变体沿用「纸片仍暖白、桌面变暗」的策略，但纸片本身不降亮度——这是刻意选择（纸就是纸）；如果实测刺眼，可加 `--lp-night-paper: #F5EFE2` 降一档。

## 不适用场景

- 需要「高密度数据 / 多窗口监控」的场景：手账语言适合一屏一焦点，不适合塞 20 个指标。
- 纯深色主题的强制产品线（例如必须全黑的专业工控界面）：纸片暖白会成为异类。
- 需要强动效与游戏化反馈的场合：本方案的动效克制且 ≤ 320ms，情绪表达靠静态形状与文案。
- 极低端设备且同时开多只桌宠：多张带投影的纸片叠加时 GPU 合成成本上升，需要限制同时显示数量（建议 ≤ 3）。
