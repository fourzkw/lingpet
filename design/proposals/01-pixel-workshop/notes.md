# 方案 A · 像素工坊（PIXEL WORKSHOP）

## 一句话主张

把像素角色自己的世界做成界面：深靛底、米白字、琥珀强调，0 圆角 + 2px 硬描边 + 4px 位移硬投影 + steps() 帧动画——像素是它的母语，秩序是现代的，不是给后台贴一层复古皮肤。

## 关键词

8px 网格 · 0 圆角 · 2px 硬描边 · 4px 位移硬投影 · 像素斜角（chamfer 6/8/12）· steps() 帧动画 · 5×5 点阵图标 · ≤6 个功能色 · 焦点只给角色

## 为什么适合灵伴

1. **角色本来就是像素画**：桌宠素材（deepseek / claude 八态）是像素角色，UI 用像素语法是「它的世界延伸出来」，而不是给一个深色 SaaS 后台换皮；工作台不会比角色更「高级」，两者是一套东西。
2. **透明窗口本来就不是一个方形面板**：原窗口是透明无边框 512×512，浮层只该有角色 + 一条状态胶囊 + hover 操作条。像素风天然允许「没有矩形底板」，反而比圆角卡片更贴合。
3. **常驻桌面要求低存在感**：近黑底（#0a0a10）在深色编辑器/终端旁不抢眼；状态只靠 3px 色条 + 点阵图标 + 2 帧闪烁，不闪大色块，长时间陪伴不累。
4. **开发者用户吃这套秩序**：8px 网格、Consolas 数字、全大写英文辅助标签（`PIXEL WORKSHOP` / `DSH · 00:42`）都是开发者熟悉的语言；像素 = 精确，不是怀旧。
5. **可落地**：无 web font、无图片资源依赖（图标是 rect 拼的、面板是 CSS 边框 + box-shadow），全部可用现有 CSS/JS 在 Electron 45 里实现，包体零增长。

## 视觉系统

### 色彩（含状态色语义）

- 主色板 9 色：`bg #0a0a10` / `surface #14141f` / `surfaceAlt #1b1b2a` / `line #2c2c42` / `textMuted #a8a2ba` / `text #f2ead8` / `accent #ffa63d`（琥珀，主操作、当前项、焦点）/ `secondary #59c9d6`（冰蓝，超链接、信息、等待输入）/ `accentSoft #33230f`（琥珀底）。
- 功能色 ≤6：琥珀（主）、冰蓝（次）、以及状态用的金/薄荷/珊瑚/红只出现在小面积（3px 状态条、点阵图标、坏帧），不做大面积铺色。
- 状态色语义：空闲 `#8d93ab` 灰蓝（低存在感）；思考中 `#ffa63d` 琥珀（正在动脑）；执行工具 `#ffd166` 金（最亮，可扫一眼）；等待输入 `#59c9d6` 冰蓝（轮到你，但不逼）；等待确认 `#ff8fa3` 珊瑚（有风险，需要人）；完成 `#7ee2a8` 薄荷（正向、短时）；错误 `#ff5f5f` 红（只在失败时出现，30 秒自动降回）；休眠 `#6f7391` 暗紫灰（几乎融入背景）。
- 浅色宿主（DSH 设置页）用 `lightVariant`：`bg #f2ecdd` / `text #1b1b26` / `accent #c2691c`，同结构不同值；深色高亮用 `color-mix(in srgb, currentColor 6%, transparent)` 派生，保证注入页面后仍跟随宿主。
- 对比度：body/meta 文本对 bg ≥ 4.5:1；`textFaint #6f6a88` 只用于 7px 以下 mono 注释（装饰性）。

### 字体与字阶

- 中文只有 Microsoft YaHei（无像素中文字体）→ 像素感由**字距 + 字重 + 短行**制造：display 40px/700/字距 8px；micro 10px 全大写 + 字距 1.2px。
- 英文/数字/代码一律 Consolas（`'Cascadia Mono', ui-monospace` 兜底）：标签、时间戳、序号、键盘提示。
- 7 档字阶（size/weight/lineHeight）：display 40/700/48 · h1 28/700/38 · h2 20/650/30 · body 14/400/24 · meta 12/400/20 · mono 12/400/20 · micro 10/400/16。
- 标题也「小写视觉体量、大写辅助标签」：中文标题用 650~700 字重，紧邻一行全大写英文（`PIXEL WORKSHOP / 灵伴`）做节奏；正文行宽 ≤ 68 字符。

### 形状与描边

- 圆角全 0；形状个性由**像素斜角**表达：`chamfer 6 / 8 / 12`（clip-path 或 SVG path 切角，切角步进 = 2px 的倍数）。
- 焦点元素：2px 硬描边 + `4px 4px 0 #050509` 位移硬投影（像贴纸被放在桌面上）。信息区退到 1px 细线，避免满屏硬边显廉价。
- 只用两种「浮起」：sticker（2px 边 + 4px 投影）与 panel（1px 线，零投影）。第三条层级用背景色差，不加模糊阴影。
- 按钮按下：整体位移 2px、投影缩到 2px（等价按下）；禁用态只降透明度到 38%，不改形状。

### 光影与纹理

- 硬投影 `4px 4px 0 #050509`（面板/弹层）、`2px 2px 0 #050509`（控件）；**不用盒阴影模糊**，避免 SaaS 味。
- 发光只给角色：径向 `0 0 40px rgba(255,166,61,.32)` 在角色脚下一层，UI 元素不发光；
- 纹理三件套：8px 点阵（面板底纹，3px 白点 8% 透明度）、4px 斜纹（进度条/强调条，`repeating-linear-gradient` 2px 白线 12%）、撕裂噪点（dither，仅用在空状态与 hero 背景，静态 CSS 渐变，不引图）。

### 动效语言

- 全部 `steps()`，不做缓动：状态点 2 帧闪烁 `steps(2) 900ms`；进度条 8 帧 `steps(8) 1200ms`；气泡弹出 4 帧 `steps(4) 160ms`（scale 0.9→1，逐帧）；按钮按下 `translate(2px,2px) steps(1) 80ms`。
- 帧数控制在 2/4/8，动画只发生在「状态变化」与「用户操作反馈」两处；常驻元素（角色待机）用素材自带帧循环，不用 CSS 持续动画（省电）。
- `prefers-reduced-motion: reduce` → 所有 duration 降到 0.01ms，只保留终态；不用动画也能从颜色 + 图标 + 文案读懂状态。

### 图标与图形

- 状态/操作图标全部是 5×5 或 7×7 的点阵（用 `<rect>` 小方块拼，unit 2/3/4 → 图标 12/18/24px），落 2px 子网格；不做抗锯齿描边图标。
- 品牌符号：8×8 像素「灵」字方块（琥珀底 + 深靛字），可用 CSS `box-shadow` 像素画或内联 SVG 实现，24px 与 16px 两档。
- 装饰只用方块与直角 L 角标（brackets），不用圆点/圆环。

## 各表面设计要点

- **桌宠浮层（01）**：透明 512×512，不画矩形底板。角色 1:1 像素（`image-rendering: pixelated`），脚下 1:1 贴地、上方状态胶囊（`PX 8 / 高 34`）+ hover 才出现的操作条（工作台/换角色/隐藏）+ 完成气泡（4 帧弹出，DONE 后点击进工作台）。胶囊与气泡都必须可用 `pointer-events: none` 之外的区域不响应鼠标。
- **快捷控制（02）**：右键光标弹层，宽 320（本方案板图用 336 含 2px 边），光标 +12px 定位、近边翻转；高 ≤ 100vh−80，内容区滚动（`overscroll-behavior: contain`）；4 只桌宠行 + 显示/大小/跟随 + 进入工作台（主按钮），Esc/外部点击关闭，关闭后焦点回触发元素。
- **工作台（03）**：1130×850 主窗口。左栏 244px 品牌 + 两导航 + 我的桌宠 + 新增桌宠；主区「当前：默认桌宠」条 + 实时预览舞台（角色 + 状态胶囊 + 隐藏桌宠）+ 右侧 tab（外观与显示 / 会话跟随）内选择角色（3 卡）+ 选择形象（已保存/原图·像素）+ 大小三档 + 开关；底部状态栏放桌宠运行状态/恢复继承配置/会话偏好。焦点顺序：左栏 → 预览 → tab → 角色 → 形象 → 大小。
- **市场（04）**：客户端内页。标题 + 3 tab（发现桌宠/投稿作品/查询投稿）+ 搜索（`搜索桌宠、作者或介绍`）+ 导入本地包 + 安装方式下拉 + 作品卡（102px 封面 1:1 贴图、引擎标签、安装态）；与静态站同源同组件。
- **DSH 面板（05）**：注入宿主，宽 460；面板自身用 `color-mix(in srgb, currentColor …)` 取宿主底色，强调色先读 `--lp-accent`、没有则桃色回退；`你的会话伙伴` checkbox + 运行状态胶囊 + `打开工作台` 主按钮；浅色宿主同一结构走 lightVariant。
- **市场网站（05 右）**：静态站 hero + 3 精选卡 + 页脚；与客户端卡片同一 DOM/样式（共用 tokens），保证同一个作品在两处视觉一致。

## 落地映射

**要改的文件**（按现有 7 个样式表 + DSH 注入处）：

- `desktop/ui-theme.css`：新增 `:root` 变量表（见下），删掉散落的 139 个色值改用 var。
- `desktop/pet.css`：状态胶囊（`steps()` 闪烁、边框 2px、硬投影 4px）、hover 操作条、气泡 4 帧弹出、`image-rendering: pixelated`。
- `desktop/quick-controls.css`：320 宽弹层、行高 44、滚动容器、Esc/外点关闭。
- `desktop/control.css`：拖拽条 260×92、8px 吸附。
- `desktop/settings.css`：工作台（左栏 244、舞台、tab、角色/形象卡、开关/滑杆）改 0 圆角 + 2px 边。
- `desktop/sidebar-app.css`：编辑器侧边栏同 tokens。
- `market/web/style.css`：与客户端共用同一变量文件（静态站单独打包时复制同一份 `:root`）。

**CSS 变量表**（tokens.json 一一对应）：

```css
--lp-bg:#0a0a10; --lp-surface:#14141f; --lp-surface-alt:#1b1b2a;
--lp-line:#2c2c42; --lp-line-strong:#464666;
--lp-text:#f2ead8; --lp-text-muted:#a8a2ba; --lp-text-faint:#6f6a88;
--lp-accent:#ffa63d; --lp-accent-soft:#33230f; --lp-accent-ink:#16100a;
--lp-secondary:#59c9d6;
--lp-radius:0; --lp-border:2px; --lp-border-soft:1px;
--lp-shadow:4px 4px 0 #050509; --lp-shadow-ctl:2px 2px 0 #050509;
--lp-glow:0 0 40px rgba(255,166,61,.32);
--lp-ease:steps(2,end); --lp-fast:120ms; --lp-base:160ms; --lp-slow:900ms;
--lp-chamfer:8px; --lp-grid:8px;
```

**需要新增的类**：`.px-panel`（1px 线）、`.px-sticker`（2px 边 + 4px 投影）、`.px-chamfer-6/8/12`（clip-path 斜角）、`.px-btn`（按下位移 2px）、`.px-chip`（状态胶囊，`--st` 变量驱动颜色）、`.px-glyph`（5×5 点阵，`--u` 控制 unit）、`.px-tab`、`.px-slider`（三段吸附 80/100/120%）、`.px-toggle`（steps(2) 位移）、`.px-badge`（已保存/HOVER）。状态色通过 `[data-state="working"]` 设 `--st: var(--lp-state-working)`，组件只读 `--st`。

**性能注意**：像素图标用 `box-shadow` 拼点（单元素 0 请求）或内联 SVG（单文件 < 2KB）；不用模糊 box-shadow 与 backdrop-filter（透明窗口合成开销）；角色贴图 `image-rendering: pixelated` + `will-change: transform` 只在切换时提升图层，待机不动画（省电，笔记本用户敏感）；`steps()` 动画全部走 `transform/opacity`，不触发布局。

## 取舍与风险

- **像素风最容易显廉价**：救场手段是「严格 8px 网格 + 极少色数 + 只在焦点元素用力（桌宠/状态/徽章/主按钮）+ 信息区保持安静」。若执行走样（网格不齐、描边粗细混用、硬投影乱加），会立刻变成「复古皮肤」。这一点是本方案最大风险，也是评审时最该盯的。
- **中文没有像素字体**：像素感靠字距/字重/网格，靠不了字形；所以标题不能做得太「街机」，否则中文会露馅。display 40px 只用在板图封面与空状态，产品内最大 h1 28px。
- **硬投影与 DISPLAY 缩放**：Windows 125%/150% 缩放下，4px 投影取整可能变 3 或 5px——用 `box-shadow: calc(4px * var(--dpr-fix))` 或统一用偶数 px 并在 150% 下接受 6px；像素斜角用 `clip-path` 会抗锯齿，边缘略糊，可用 2px 描边掩盖（已按此设计）。
- **状态色区分度**：琥珀（思考）与金（执行）色相接近，靠图标形状与动效节奏（3 点轮闪 vs 8 帧进度）区分；色弱用户靠文案 + 图标仍可读。
- **浅色宿主注入**：DSH 设置页为浅色时，`surface` 必须由 `color-mix(currentColor)` 派生而不是写死深靛，否则会突兀；已在 05 节给出浅色变体。

## 不适用场景

- 不适合做「长文档/代码编辑器」界面：0 圆角 + 2px 描边在密集信息下会吵，代码/日志区应退回系统字体与 1px 线（本方案已把正文区降级为 1px，但若产品要加代码预览页，需另做中性主题）。
- 不适合亮色环境下的大面积使用：亮色桌面 + 深靛大窗对比强，需要 lightVariant 或更高透明度融合；桌面壁纸极亮时建议降低窗口不透明度或启用浅色变体。
- 不适合营销落地页/品牌官网：像素工坊是工具的语气，不是 campaign 的语气；市场静态站沿用它是为了内外一致，但对外品牌页应另做。
- 不适合高密度表格/后台管理页：8px 网格与大字距会显著降低单屏信息量，本方案只覆盖桌宠相关 5 个表面。
