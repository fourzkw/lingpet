# 方案 02 · 暖光夜桌（WARM NIGHT DESK）

> 板图：`board.png`（1600 × 6249） · Token：`tokens.json` · 生成脚本：`board.mjs`（`node board.mjs` 重渲染）

## 一句话主张

**把桌宠当作深夜书桌上的一盏灯：深棕夜色做底，玻璃卡片承托，光晕随状态换色，界面退到角色之后。**

## 关键词

`夜间` `暖光` `玻璃` `呼吸` `克制的仪式感`

## 为什么适合灵伴

1. **桌宠是常驻的**：它会在深夜、游戏全屏、写代码时一直挂在屏幕上。深棕夜色（#0b0908 / #171210）比中性深灰更像「夜里开了台灯的房间」，长时间看不刺眼；状态光晕给的是环境光，而不是告警色块。
2. **像素角色需要「被托住」**：像素画本身色域窄、边缘硬。用一圈暖橙 radial 光晕 + 一块更暗的舞台底，角色从桌面「浮」起来，比现在的深色长方块更像角色活着。
3. **状态是产品核心**：8 个状态（空闲/思考/执行/输入/确认/完成/错误/休眠）现在只有一个 6px 圆点。方案把状态变成三层语言：光环颜色 + 胶囊文字 + 专属微 UI（思考三点、确认卡、失败 toast），一眼可读但仍安静。
4. **开发者桌面**：VS Code / Cursor / 终端都是冷色深色。暖棕底 + 橙色强调在冷色桌面里反而「认得出是宠物不是又一个弹窗」，且不抢焦点。
5. **成本低**：不引入图片素材、不引入新依赖，全部用 CSS 渐变 / 半透明 / 1px 内高光实现；`backdrop-filter` 只用在浮层（≤2 处），透明窗口里也有降级方案。

### 字体与字阶

- 展示：`'Noto Serif SC','Microsoft YaHei',serif` —— 中文衬线给「夜里读信」的温度，只用于页面主标题 / 品牌 / 卡片大标题。
- 界面：`'Microsoft YaHei','Noto Sans SC',sans-serif` —— 正文与控件。
- 等宽：`Consolas,'Courier New',monospace` —— 状态、会话 id、版本号、数字；字号更小一档，形成「机器信息」层。

| 级别 | 字号 / 字重 / 行高 | 字体 | 用途 |
| --- | --- | --- | --- |
| display | 30 / 700 / 38 | Noto Serif SC | 页面主标题、品牌 |
| h2 | 20 / 700 / 28 | Noto Serif SC | 卡片与分区标题 |
| h3 | 15 / 600 / 22 | YaHei | 区块标题 |
| body | 12.5 / 400 / 21 | YaHei | 正文、描述 |
| meta | 10 / 400 / 15 | YaHei | 元信息 |
| mono | 9.5 / 400 / 14，字距 .3 | Consolas | 状态、版本、数字 |
| micro | 9 | YaHei | 脚注（仅非关键信息） |

三级层次来自「衬线大字 + 无衬线正文 + 等宽小字」，而不是靠加粗和颜色堆叠。

### 形状与描边

- 圆角：窗口 18 / 面板 16 / 卡片 12 / 控件 10 / 小标签 8 / 胶囊 999。全程无 0 圆角（像素角色已经够硬，界面要软）。
- 描边：永远 1px 暖灰（`#33291f`）；只有选中态升到 1.5px 暖色（`#f0a860`）。
- 内高光：玻璃卡片顶部一条 `inset 0 1px 0 rgba(255,215,174,.10)`，是「厚度」的唯一来源。
- 图标：1.5px 线性、圆角端点、24px 网格；不用实心填充图标（会和像素角色抢视觉重量）。

### 光影与纹理

- 阴影一律向下：面板 `0 22px 54px rgba(0,0,0,.55)`、卡片 `0 12px 30px rgba(0,0,0,.45)`、浮层 `0 10px 24px rgba(0,0,0,.5)`。
- 发光**只**给两处：桌宠光环、状态灯。按钮、卡片、选中态不发光（避免「全屏霓虹」）。
- 纹理：`dotGrid` 2% 点阵与 `scanline` 只出现在舞台/封面/品牌区，透明度 ≤6%。

### 动效语言

- 缓动统一 `cubic-bezier(.2,.8,.2,1)`；时长 fast 140 / base 240 / slow 320。
- 光晕「呼吸」4s（thinking 时 2.4s 并收窄半径）；气泡出现 320ms 从角色方向滑入 8px；状态切换 240ms 只做透明度 + 颜色。
- 错误闪两下（120ms × 2）后停在红色状态，不做持续闪烁。
- `prefers-reduced-motion: reduce`：全部呼吸/位移取消，只保留 140ms 透明度过渡。

### 图标与图形

- 状态灯：8px 圆点 + 外圈同色 30% 光斑（CSS `box-shadow` 实现，不用图标）。
- 操作图标（工作台 / 换角色 / 隐藏）：1.5px 线性、圆端、24px 网格，鼠标 hover 才出现的三个玻璃圆钮。
- 徽章（已保存 / 状态胶囊）：胶囊 + 文字 + 可选小圆点；不用彩色大色块。

## 各表面设计要点

### 1. 桌宠浮层（透明窗口）

- 角色本体不动，**背后加一层 `.aura`**：径向渐变、`mix-blend-mode: screen`、半径随状态 144→176px、`animation: breathe 4s`。
- 状态胶囊从「深色实心块」换成**玻璃胶囊**：`background: linear-gradient(140deg, rgba(44,36,29,.92), rgba(26,21,18,.94))` + `1px` 暖灰描边 + `inset 0 1px 0 rgba(255,215,174,.12)`；左侧 6px 圆点换成 8px 状态灯（带 30% 光斑）。
- 互动气泡：奶油底 `#fdf5e8` 到 `#f3e5d0` 轻微渐变、16px 圆角、右下角朝向角色的三角、`0 12px 30px rgba(0,0,0,.45)`；标题用衬线 15.5px（「改完了，要看看吗？」），补充行用等宽 10.5px。
- hover 三圆钮：32px 玻璃圆、图标 1.5px 线性、间距 14px，整体 `opacity 0 → 1` 140ms。
- 透明窗口注意：不做整屏遮罩、不用大面积 `backdrop-filter`（改用半透明渐变模拟玻璃），保证 Windows 下拖动不卡。

### 2. 快捷控制面板（右键浮层）

- 356 × 566 玻璃面板，18px 圆角，头部「灵伴 · 快捷控制」+ 右上关闭。
- 4 只桌宠行：58px 行高、38px 缩略图、选中行 = 暖色 12% 底 + 1.5px 暖描边 + 右侧当前状态胶囊；每行右侧一个 `switch`（开关桌宠显示）。
- 大小滑杆：3px 轨道，滑块 17px 暖色 + 3px 光斑；三档文字（小/中/大）用 10px muted。
- 底部主按钮「进入工作台」：暖橙渐变，文字用 `--lp-accent-ink`。
- 拖拽控制条（贴边时出现）：330 × 86，缩略图 + 会话名 + 状态胶囊 + 隐藏钮；整体 25% 不透明度，hover 100%。

### 3. 桌宠工作台（1130 × 850，可压到 900）

- 侧栏 280px：暖黑垂直渐变、右侧 1px 线；品牌 = 44px 暖色圆角方块「灵」（衬线 24px）+ 灵伴（衬线 21px）/ LINGPET（等宽 8.5px 字距 2.6）。
- 导航选中态 = **左缘 2.5px 暖光条 + 12% 暖底**，而不是整块亮色块（夜间安静）。
- 「我的桌宠」列表：58px 行，38px 缩略图，选中行同导航；右侧「删除」用 10px faint，hover 才显形。
- 主区：标题衬线 30px + 副标题 12.5px；右上连接胶囊（`.` 绿点 + 等宽 10px）。
- 实时预览面板 520px 宽：暗舞台 + 虚线环（1px，`--lp-line-strong`，`stroke-dasharray 4 6`）+ 光晕 + 角色 208×274 + 玻璃状态胶囊；下方「隐藏桌宠」主按钮（44px 高）；底部大小滑杆。
- 右列：tab（选中 = 表面 + 1.5px 暖描边）、角色卡两列（选中 = 暖描边 + 右上 ✓）、形象卡（左侧 160×124 封面、右侧「已保存」徽章 + 名称 + 原图/像素切换）、两个开关行、底部「重置默认外观」ghost 按钮。
- 字重分层：衬线大标题（30）+ 无衬线正文（12.5）+ 等宽元信息（9.5），标题与内容之间用留白分开，不用分隔线堆叠。

### 4. 桌宠市场

- 与工作台共用同一套 token；标题衬线 27px，tab 选中 = 暖色文字 + 2px 暖色下划线（不是胶囊），搜索框 40px 高。
- 作品卡：封面 184px（暗色渐变 + 光环 + 角色），左下角「像素 · 8 态」玻璃标签，卡底 76px 放名称（15px 600）+ 作者（10px faint），右下「安装」按钮（首项主色、其余抬升色）。
- 空状态：一句衬线文案 + 一行等宽说明，不留大块灰字。

### 5. DSH 设置面板（注入宿主）

- 必须适配深浅两套宿主主题：卡片底一律 `color-mix(in srgb, currentColor 4%, transparent)`，描边 `color-mix(in srgb, currentColor 12%, transparent)`。
- 强调只用 `--lp-accent`（宿主没定义时回退 `#f0a860`），不写死六位色值。
- 结构：`LINGPET / 灵伴` 等宽眉标 → 衬线 26px 标题「你的会话伙伴」→ 说明 → 卡片「桌宠运行状态」（绿点 + 状态句 + 三个按钮，主按钮暖橙）→「会话偏好」（开关行）→ 脚注。
- 删掉现在的 `#d79d76` / `#d68c67` 硬编码，改为 `var(--lp-accent, #f0a860)`。

### 6. 市场网站（Go 站点）

- 同一套 token 落到 `market/web/style.css`：深棕底 + 暖橙强调 + 衬线大标题。
- Hero：左文（衬线 26px 两行 + 12.5px 描述 + 两个按钮）右角色（294px + 光环），下方三张作品卡。
- 顶部导航：logo（衬线「灵伴」+ 等宽 LINGPET）+ 4 个文字链接，hover 变暖色。
- 页面宽度沿用现有容器，只换 token 与字阶，不改信息架构。

性能注意：

- 透明窗口里**不要**对整个 body 用 `backdrop-filter`：用 `linear-gradient` 半透明底 + 1px 内高光模拟玻璃，视觉接近、GPU 便宜。
- 光环用 `radial-gradient` + `opacity` 动画（合成层），不要动 `filter: blur()` 半径（会重绘）。
- 呼吸动画挂在独立 `will-change: opacity` 的伪元素上，状态切换时只改 `color`。

## 取舍与风险

- **暖棕底比深灰底「有主张」**：适合夜间与长时间陪伴，但如果用户希望桌宠在浅色主题下也出现，需要浅色变体（已给出 8 个值）。
- **衬线标题是双刃剑**：中文衬线在小字号会糊，所以衬线只用于 ≥20px 的标题；正文必须无衬线。
- **光晕在亮色壁纸上会被吃掉**：透明窗口的光晕依赖暗背景。建议给桌宠窗口加一层 24px 软阴影（`drop-shadow(0 8px 24px rgba(0,0,0,.35))`），浅色壁纸上仍能立住。
- **状态色里橙色系偏多**（思考/执行/警示都偏暖）：靠亮度与位置区分——思考是缓呼吸，执行是亮脉动，警示有边框与图标，不会混。
- **工作量**：ui-theme + pet.css 改动约 80 行、settings.css 约 150 行、市场 60 行、client 20 行，可在不改结构的前提下逐文件替换（建议按此顺序上线）。

## 不适用场景

- 需要「企业控制台」式冷蓝专业感的市场后台（`admin.html`）——那里建议保留中性深色，只借用 token 里的线/字色。
- 需要高对比无障碍的场合：本方案强调色在深底上对比约 6.8:1，但光晕纯装饰；若要 AAA，需要另出高对比变体（把 muted 提到 `#d3c6b6`）。
