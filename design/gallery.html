一个像素伙伴的四种样子

灵伴是一个常驻桌面的像素角色伙伴：它跟着 DSH / Codex / Cursor 的会话切换状态，右键能叫出快捷控制，工作台里挑形象与跟随方式。 现状是一套「通用深色 SaaS 后台 + 暖桃点缀」，界面和像素角色不在同一个世界里。下面四个方案用同一套信息架构，给出四种气质。

01四个方向

每个方向都覆盖：桌宠浮层（八态）、快捷控制、工作台、市场、DSH 面板、市场网站，以及一套可落地的 token。

02怎么选

详细对比、落地顺序与风险见 README.md；四方案横向拼图见 compare.png。

建议：以「暖光夜桌」为基线，吸收另外三套的长处

  1. 主体（桌宠浮层 / 工作台 / 市场 / DSH 面板）用方案 02：改动集中在 token 与光晕，不动信息架构，一两轮就能上线。
  2. 把方案 01 的「状态图标 + 硬边框 tag」借到工作台的角色卡与市场标签上，给像素角色一点同类语言。
  3. 把方案 03 的浅色变体作为「白天主题」候选，先只做 prefers-color-scheme: light 的一版。
  4. 把方案 04 的等宽元信息层（会话 id、工具名、耗时）收进工作台的会话列表，让「机器信息」和「人话」分层。
